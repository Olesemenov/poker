# Інструкція для macOS

Усі команди виконуються в **Терміналі** (Cmd+Пробіл → введіть `Terminal` → Enter).
Проєкт поки запускається на Mac як на комп'ютері; збірки для iPhone/Android ще немає (див. `PLAN.md`, етап 7).

## 1. Інструменти розробника і git

```bash
xcode-select --install
```

З'явиться вікно: натисніть «Встановити» і дочекайтесь завершення. Перевірка:

```bash
git --version
```

## 2. Python 3.11+

Перевірте версію:

```bash
python3 --version
```

Якщо версія нижча за 3.11 або команди немає, встановіть Python одним зі способів:

**Варіант А: Homebrew** (зручніше для оновлень)

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install python@3.12
```

Після встановлення Homebrew виконайте команди, які він покаже наприкінці («Next steps»), потім перезапустіть Термінал.

**Варіант Б: інсталятор** з https://www.python.org/downloads/macos/ (оберіть 3.12).

Рекомендована версія — **3.12**: для неї у Kivy точно є готові збірки під macOS.

## 3. Завантаження проєкту

```bash
cd ~
git clone https://github.com/Olesemenov/poker
cd poker
```

## 4. Віртуальне середовище і залежності

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

Після `source .venv/bin/activate` на початку рядка з'явиться `(.venv)`. Це треба повторювати
в кожному новому вікні Терміналу, перш ніж запускати проєкт.

Якщо `pip install` скаржиться на `kivy`, створіть середовище заново з Python 3.12:

```bash
deactivate
rm -rf .venv
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 6. Онлайн-режим (сервер на вашому Mac)

```bash
python -m poker.server
```

У консолі з'являться два посилання:

- `Host:` `http://127.0.0.1:8080/?room=...&host=...` — **ваше**, з правами адміна.
  Відкрийте його у Safari або Chrome **на цьому Mac**, введіть ім'я, натисніть «Зайти за стіл».
- `Guests:` `http://192.168.x.x:8080/?room=...` — це посилання надішліть іншим гравцям (до 5 людей).

Перший запуск: macOS запитає «Do you want the application "Python" to accept incoming network
connections?». Натисніть **Allow (Дозволити)**, інакше гості не зможуть підключитись.

Гості відкривають посилання на телефоні чи комп'ютері, вводять ім'я й заходять. Усі мають
бути **в одній Wi-Fi мережі** (або в мережі, яку роздає ваш телефон).

Коли за столом є хоча б двоє, ви (хост) натискаєте «Нова роздача (host)».
Зупинити сервер: `Ctrl+C` у Терміналі.

### Якщо гості не можуть зайти

1. Чи в одній мережі? Гостьова Wi-Fi та деякі роутери вмикають «ізоляцію клієнтів»,
   тоді пристрої не бачать один одного. Спробуйте хотспот із телефона.
2. IP у посиланні `Guests` може бути неправильним (`127.0.0.1`). Дізнайтесь адресу Mac:
   ```bash
   ipconfig getifaddr en0
   ```
   (якщо порожньо, спробуйте `en1`) і замініть IP у посиланні вручну, наприклад
   `http://192.168.0.15:8080/?room=...`.
3. Фаєрвол: Системні налаштування → Мережа → Брандмауер → дозвольте вхідні підключення для Python.
4. Помилка `Address already in use`: порт 8080 зайнятий. Знайдіть процес і завершіть його:
   ```bash
   lsof -i :8080
   kill <PID>
   ```

## 7. Мобільний інтерфейс на Mac

```bash
python -m app.main
```

Відкриється вікно з меню:

- **Offline** — стіл на одному пристрої для 4 гравців. «Показати карти» → зробити хід → передати далі.
  Після завершення роздачі натисніть «Нова роздача».
- **Online** — «Створити кімнату» запускає сервер і показує посилання (так само, як у розділі 6).

Перший запуск Kivy може тривати кілька секунд.
