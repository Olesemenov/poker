# План розробки: мобільний покер (Texas Hold'em, до 6 гравців)

## Архітектура

```
poker/            чистий Python, без UI та мережі в ядрі
  cards.py        Card, Deck
  evaluator.py    оцінка рук (best of 7)
  game.py         Table: блайнди, раунди ставок, side pots, showdown
  server.py       онлайн: aiohttp + WebSocket, кімната, host/guests
  static/         веб-клієнт, який відкривається за посиланням
app/main.py       мобільний UI на Kivy: меню Online / Offline
tests/            unit + випадкові симуляції (збереження фішок)
```

Принцип: **вся логіка гри в `Table`**. Offline UI викликає її напряму, online-сервер
викликає її ж і розсилає `public_state(viewer)` (чужі карти приховані на сервері,
а не в клієнті).

## Режими

- **Offline**: один стіл на одному пристрої (hot-seat), UI — стіл, ставки, кнопки
  Fold / Check / Call / Raise / All-in, показ карт поточному гравцю.
- **Online**: пристрій хоста запускає сервер, показує посилання
  `http://<ip>:8080/?room=<код>`. Хост = адмін (старт роздачі, kick), гості (до 6 разом із хостом)
  заходять із браузера або з додатку. Мережа: одна Wi-Fi / хотспот хоста.

## Протокол (JSON через WebSocket `/ws`)

Див. docstring у `poker/server.py`: `join`, `start`, `action`, `kick` → `joined`, `state`, `error`.

## Відомі спрощення в ядрі

- Немає burn-карт (не впливає на рівність, лише на «точність» до казино).
- Короткий all-in рейз не перевідкриває торги.
- Немає таймерів, rake, докупок.
- Якщо гравець вийшов посеред роздачі — автофолд, місце видаляється після роздачі.

## Ризики

- **Android і сервер у фоні**: ОС може вбити процес, коли екран гасне → потрібен foreground service (buildozer: `android.services`).
- **Хотспот/NAT**: гості мають бути в одній мережі з хостом; для інтернету потрібен тунель (етап 9).
- **Чесність**: сервер на пристрої хоста, тому хост технічно може бачити всі карти. Для friendly-ігор ок.
- **Kivy на iOS** важчий у збірці, ніж на Android — починати з Android.

## Як запускати

```bash
python -m unittest discover -s tests -t .      # тести (лише stdlib)
pip install -r requirements.txt
python -m poker.server                         # online-сервер на ПК для розробки
python -m app.main                             # мобільний UI на ПК
```
